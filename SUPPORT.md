# Support

NOESIS-Σ / SigmaStorm is research software maintained on a best-effort basis. It is not a hosted
service and does not promise production support or a fixed response time.

## Before opening a question

Please check:

- [README.md](README.md) for installation, evaluation, and reproducibility commands;
- [DESIGN.md](DESIGN.md) for model and state details;
- [docs/FINDINGS.md](docs/FINDINGS.md) for measured findings and caveats;
- [docs/KAGGLE.md](docs/KAGGLE.md) for the optional Kaggle workflow; and
- [docs/ROADMAP.md](docs/ROADMAP.md) for known scope and future work.

## Asking for help

Open a GitHub issue for reproducible bugs, documentation problems, or usage questions. Include:

- the commit or release;
- Python, PyTorch, and operating-system versions;
- the command and configuration used;
- the smallest useful traceback or reproduction; and
- the expected and observed behavior.

Remove credentials, private paths, private data, and private checkpoints before posting logs.

## Security reports

Do not use a public issue for a vulnerability or exposed credential. Follow [SECURITY.md](SECURITY.md).
