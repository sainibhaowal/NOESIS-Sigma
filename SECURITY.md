# Security Policy

## Supported Versions

Currently, NOESIS-Σ is in **Alpha Experimental** stage. Security patches are not actively maintained for any version.

## Reporting a Vulnerability

If you discover a security vulnerability in NOESIS-Σ, please report it responsibly:

**DO NOT:**
- Create public GitHub issues for security vulnerabilities
- Disclose vulnerabilities publicly before they are fixed
- Exploit vulnerabilities for any purpose

**DO:**
- Report vulnerabilities privately via [GitHub Security Advisories](https://github.com/sainibhaowal/NOESIS-Sigma/security/advisories/new)
- Include detailed description of the vulnerability
- Provide steps to reproduce the issue
- Allow reasonable time for the issue to be addressed

## Response Timeline

- **Initial Response**: Within 48 hours of receiving a report
- **Assessment**: Within 1 week for severity evaluation
- **Fix**: Timeline depends on severity and complexity

## Severity Classification

- **Critical**: Immediate risk to data confidentiality, integrity, or availability
- **High**: Significant risk but limited impact
- **Medium**: Moderate risk with mitigating factors
- **Low**: Minimal risk or edge cases

## Security Best Practices

Since NOESIS-Σ is experimental:

1. **Do not use in production** - This is research code, not production-ready
2. **Do not process sensitive data** - Experimental systems may have unknown vulnerabilities
3. **Review code before deployment** - Understand the security implications
4. **Keep dependencies updated** - Regular security updates for dependencies
5. **Monitor for issues** - Watch GitHub security advisories

## Known Limitations

- Input validation is experimental
- Encryption features are research-grade, not production-grade
- Authentication/authorization is not implemented
- Audit logging is experimental
- No formal security audit has been performed

## Disclaimer

NOESIS-Σ is provided as-is for research purposes. No security guarantees are provided or implied. Users assume all risks associated with using this experimental software.

## Contact

For general issues: Use [GitHub Issues](https://github.com/sainibhaowal/NOESIS-Sigma/issues).
